# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GrokZomborg Evolved, please email robisonpedroso0089@gmail.com instead of using the public issue tracker.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

## Response Time

- Acknowledgment: Within 48 hours
- Status update: Within 5 days
- Fix release: Within 30 days

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | ✅ Yes    |
| 1.x     | ❌ No     |

## Security Best Practices

1. Keep dependencies updated
2. Never commit secrets or API keys
3. Use environment variables for sensitive data
4. Enable GitHub's secret scanning
5. Validate all user inputs
6. Use HTTPS for all communications

Thank you for helping keep our project secure!
