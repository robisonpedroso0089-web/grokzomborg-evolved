# Contributing to GrokZomborg Evolved

We appreciate your interest in contributing to GrokZomborg Evolved! This document provides guidelines for contributing to the project. By following these guidelines, you can help keep the contributions organized and efficient.

## Code Style

- Use [Prettier](https://prettier.io/) for formatting JavaScript code.
- Follow the [Airbnb JavaScript Style Guide](https://github.com/airbnb/javascript).
- Use descriptive variable and function names.
- Write comments where necessary to explain complex logic.

## Pull Request Process

1. **Fork the Repository**: Create your own fork of the repository on GitHub.
2. **Create a Branch**: Do all your work in a separate branch. Use a descriptive name for your branch related to the feature you are implementing or the bug you are fixing.
3. **Commit Your Changes**: Write clear, concise commit messages. A good format is: `Fix: fixed a bug`, `Feature: added new feature`.
4. **Push to Your Fork**: Push your changes to your fork on GitHub.
5. **Open a Pull Request**: Navigate to the original repository and create a pull request. Clearly explain your changes and why they are necessary. Use the template provided.
6. **Address Feedback**: Be prepared to discuss and make changes based on feedback from the repository maintainers.

## Issue Reporting

When reporting an issue, please follow these guidelines:

- **Use a Clear Title**: The title should summarize the issue clearly.
- **Provide a Description**: Include steps to reproduce the issue, what you expected to happen, and what actually happened.
- **Include Relevant Information**: If applicable, include screenshots, error messages, or other relevant details.

Thank you for contributing to GrokZomborg Evolved! Your contributions help improve the project for everyone!
