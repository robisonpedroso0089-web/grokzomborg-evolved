# Support

## Getting Help

If you need help with GrokZomborg Evolved, here are the best ways to get support:

### Documentation
- Check the README.md for getting started
- Review CONTRIBUTING.md for contribution guidelines
- Look at existing issues and discussions

### Reporting Issues
- For bugs: Use the Bug Report template
- For features: Use the Feature Request template

### Security Issues
- DO NOT open a public issue for security vulnerabilities
- Email: robisonpedroso0089@gmail.com
- See SECURITY.md for details

### Community
- Check existing GitHub Discussions
- Join our community conversations

## Response Times

- Bug reports: Reviewed within 48 hours
- Feature requests: Reviewed within 1 week
- Security issues: Reviewed within 24 hours
